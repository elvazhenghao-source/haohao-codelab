YEAR 2

Advanced Computer Science & Application Development

Algorithms · Data Structures · Software Development · Web Applications

01 · Algorithms & Computational Thinking

Develop logical and algorithmic thinking to solve increasingly complex problems. Learn to design efficient solutions and understand how computer programs process information.

Algorithm Design · Problem-Solving · Computational Complexity · Optimization

02 · Data Structures & Problem-Solving

Explore how information is organized and processed. Apply different problem-solving strategies to build a deeper understanding of computer science.

Data Structures · Logical Reasoning · Algorithm Applications

03 · Software & Application Development

Move beyond basic programs and create interactive software applications. Learn to design user interfaces, integrate external services, and build practical tools.

Application Development · GUI Design · API Integration · Interactive Projects

04 · Data Analysis & Predictive Modeling

Discover how to work with real-world data, identify patterns, visualize information, and explore how data can be used to make predictions.

Data Processing · Data Analysis · Visualization · Predictive Modeling

05 · Web Development & Full-Stack Applications

Learn how modern web applications work, from interactive user interfaces to back-end systems. Combine different technologies to build complete, dynamic web applications.

Web Development · Frontend & Backend · Dynamic Applications

By the End of Year 2

Students will develop a deeper understanding of computer science and gain practical experience in algorithm design, data analysis, software development, and web applications.

They will be ready to take the next step into artificial intelligence, machine learning, and large language model technologies in Year 3.
