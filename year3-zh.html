第三年

人工智能与创新实践

人工智能 · 大语言模型 · 机器学习 · AI 应用

01 · 人工智能与大语言模型基础

探索人工智能的工作原理，理解机器学习、深度学习与大语言模型之间的区别，认识现代 AI 系统背后的核心技术与基本机制。

人工智能 · 机器学习 · 深度学习 · 大语言模型 · Transformer · Attention 机制

02 · 大语言模型接口与 AI 应用开发

学习通过 API 将大语言模型接入自己的程序，掌握 Prompt 设计、AI 返回结果处理等方法，将智能功能融入 Python 和 Web 应用。

LLM API · Prompt Engineering · 结构化输出 · API 集成 · AI 应用开发

03 · AI 辅助软件工程

探索 AI 编程工具如何改变软件开发方式。学习使用 Codex 等工具规划、编写、调试和优化复杂项目，同时理解项目架构、代码结构及各个功能模块的作用。

AI 编程工具 · 项目架构 · 代码生成 · 程序调试 · 软件测试 · 软件开发

04 · 机器学习与预测建模

理解计算机如何从数据中学习并进行预测。探索基础机器学习方法，使用 Python 训练和评估模型，并将预测能力应用于实际项目。

监督学习 · 回归 · 分类 · 模型训练 · 模型评估 · 数据预测

实践项目

学生将通过逐步深入的项目实践，综合运用所学的 AI 和编程知识。

  • AI 文本助手：开发能够进行文本生成、总结和问答的智能助手。
  • 机器学习预测系统：训练机器学习模型，并开发能够根据数据进行预测的应用。
  • AI 智能应用：结合 AI API、Python 和 Web 技术，开发具有实际功能的智能工具。

完成第三年学习后

学生将理解人工智能、机器学习和大语言模型的基本原理，能够将 AI 接口集成到软件应用中，使用 AI 编程工具辅助开发复杂项目，训练基础机器学习模型，并综合运用不同技术构建智能应用。
