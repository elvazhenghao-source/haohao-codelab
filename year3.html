YEAR 3

Artificial Intelligence & Innovation

Artificial Intelligence · LLMs · Machine Learning · AI Applications

01 · Understanding Artificial Intelligence & LLMs

Explore how artificial intelligence works and understand the differences between machine learning, deep learning, and large language models. Discover the fundamental ideas behind modern AI systems.

Artificial Intelligence · Machine Learning · Deep Learning · Large Language Models · Transformers · Attention Mechanism

02 · LLM APIs & AI Application Development

Learn to connect applications with powerful AI models through APIs. Design effective prompts, process AI-generated responses, and integrate intelligent features into Python and web applications.

LLM APIs · Prompt Engineering · Structured Responses · API Integration · AI-Powered Applications

03 · AI-Assisted Software Engineering

Explore how AI coding assistants can transform software development. Use tools such as Codex to plan, build, debug, and improve complex projects while understanding their architecture, code structure, and functionality.

AI Coding Tools · Project Architecture · Code Generation · Debugging · Testing

04 · Machine Learning & Predictive Modeling

Discover how computers learn from data and make predictions. Explore fundamental machine learning methods, train models using Python, and integrate predictive capabilities into practical applications.

Supervised Learning · Regression · Classification · Model Training · Model Evaluation · Prediction

Hands-on Projects

  • AI Text Assistant — Build an assistant for writing, summarizing, and answering questions.
  • Machine Learning Predictor — Train models and build a data-driven prediction application.
  • AI Knowledge Assistant — Build a document-based question-answering application using AI.
  • AI-Powered Applications — Combine AI APIs, Python, and web technologies to create practical applications.

By the End of Year 3

Students will understand the fundamentals of artificial intelligence, machine learning, and large language models. They will be able to integrate AI APIs into applications, use AI coding assistants to develop complex projects, build basic predictive models, and combine different technologies to create intelligent applications.

Most importantly, students will develop the ability to think independently, evaluate AI-generated solutions, and use technology creatively to solve real-world problems.
